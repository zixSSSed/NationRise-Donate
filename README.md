# NationRise — донат-магазин

Витрина магазина сервера **NationRise**. Статический сайт + одна серверная функция
для создания платежа в EasyDonate.

Открыть: [nationrise.space](https://nationrise.space)

## Структура

| Путь | Что это |
|---|---|
| `index.html` | весь сайт: каталог, корзина, окна товаров, темы |
| `functions/api/pay.js` | Cloudflare Pages Function — создаёт платёж в EasyDonate |
| `img/` | картинки товаров (`<id>.png`), необязательны |
| `ИКОНКИ-ПРОМПТ.md` | инструкция и промпт для генерации иконок |

## Как править товары

Все товары лежат в массиве `PRODUCTS` внутри `index.html`. У каждого:

- `price` — цена в рублях (у привилегий вместо неё `variants`: 30 / 90 дней / навсегда);
- `edId` — ID товара в EasyDonate (у привилегий — объект `ed` с ID на каждый срок);
- `desc` — короткая подпись на карточке.

Подробные описания (окно по клику) — в объекте `DETAILS`. Текст в `§...§`
подсвечивается золотым.

## Иконки

Файл `img/<id>.png` подхватывается автоматически, править код не нужно.
Если файла нет — рисуется векторная заглушка. Подробности в `ИКОНКИ-ПРОМПТ.md`.

## Оплата

Ключи EasyDonate задаются переменными окружения проекта Cloudflare Pages —
в репозитории их нет и быть не должно:

- `SHOP_KEY` — ключ магазина EasyDonate (32 символа);
- `SERVER_ID` — ID сервера из панели EasyDonate.

Пока переменные не заданы, кнопка оплаты честно сообщает, что оплата настраивается.
